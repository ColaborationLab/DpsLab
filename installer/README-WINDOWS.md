# DpsLab para Windows

1. Extrae por completo el archivo ZIP en una carpeta con permisos de escritura.
2. Abre `DpsLab\DpsLab.exe`.
3. En WoW ejecuta `/dpslab export app`, confirma la recarga y vuelve a la app.
4. Confirma que la app identifica la clase y especialización exportadas, elige de una a cuatro builds del mismo personaje y especialización, o añade cadenas de talentos manuales con nombre, y ejecuta la comparación.
5. La app compara únicamente DPS entre esas builds y conserva el contexto de clase/especialización al guardar un caso. No presenta DPS como curación o supervivencia, ni reutiliza pesos de Balance fuera de Balance.
6. En WoW ejecuta `/reload` y `/dpslab result` para ver el resultado.

La distribución contiene `simc.exe`; no se necesita una instalación separada de SimulationCraft.
