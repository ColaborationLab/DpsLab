# DpsLab para Windows

1. Extrae por completo el archivo ZIP en una carpeta con permisos de escritura.
2. Abre `DpsLab\DpsLab.exe`.
3. En WoW ejecuta `/dpslab export app`, confirma la recarga y vuelve a la app.
4. Confirma que la app detecta de dos a cuatro builds de Balance, o añade cadenas de talentos manuales, y ejecuta la comparación.
5. La app muestra los DPS, los pesos compatibles con Pawn y la puntuación de los ítems exportados. Puedes guardar un caso para revisarlo después.
6. En WoW ejecuta `/reload` y `/dpslab result` para ver el resultado.

La distribución contiene `simc.exe`; no se necesita una instalación separada de SimulationCraft.
