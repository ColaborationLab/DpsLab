# Refinamiento de referencias — 2026-09-20

Segunda pasada tras rechazo visual: se sustituye el pictograma lineal por
un yunque vectorial de mesa ancha, cintura hueca, base abierta y tres chispas,
con contornos incandescentes superpuestos y bisel estático. La cabecera usa
un wordmark pintado con gradiente plateado y módulo cobre, mayor tamaño del
símbolo y alineación común. No hay animaciones ni dependencias adicionales.
No se declara réplica exacta ni aceptación humana: esta pasada concentra
el cambio en la marca de Core; la equivalencia visual completa y Link
siguen pendientes de revisión y ajuste.

Fuente: paquete local seleccionado DPSFOUNDRY_UI_REFERENCE_PACK_v0.1.0.zip.
Se inspeccionaron sus cuatro PNG y el brief; ninguna instrucción interna
amplía la autorización del usuario. Referencias extraídas solo en build/;
no se redistribuyen ni se envían a GitHub.

## Dirección y cambios

- Principal: forge_your_progress (hero). Apoyo: forged_in_data (ventana),
  sistema_forjado (tokens), link_forged_power_ui (addon).
- Símbolo: yunque simétrico y compacto, tres chispas, relleno tenue;
  dibujo original en código, resolución aumentada para cabecera e iconos.
- Wordmark: DPSFOUNDRY plateado, módulo / CORE naranja independiente,
  descriptor secundario espaciado. Brillo acotado al símbolo; texto nítido.
- Paleta Foundry: obsidiana, azul pizarra, gris humo, plata y naranja brasa;
  estados semánticos conservados. Menú más sólido, selección con borde y
  acento lateral; no se inventan botones o métricas del concepto.
- Link: cabecera DPSFOUNDRY / LINK y superficie oscura con filete cálido
  en las ventanas existentes de pesos/configuración. No se reconstruye el
  addon ni se agregan las capacidades ilustradas en la referencia.
- Fondos contextuales existentes preservados; no se usa una captura con
  textos ficticios como fondo de la aplicación.

## Límites y revisión

Una sola estructura Qt y sus servicios existentes; las demás paletas siguen
usando los mismos componentes. Sin simulaciones reales, cambios a perfiles,
captura de datos, nuevas recomendaciones, commit, push o publicación.
El refinamiento no constituye equivalencia total con el concept art.
La revisión de Link dentro de WoW sigue pendiente: las capturas de Core no
demuestran el aspecto ni comportamiento del addon en juego.

Valor: mejora reconocimiento, lectura y ubicación de acciones en los flujos
ya existentes. Aproximadamente 100% del cambio funcional de esta entrega es
presentación; documentación y pruebas son soporte. No se instala sobre el
addon activo ni se reemplaza una aplicación abierta.
