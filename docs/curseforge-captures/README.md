# Capturas beta para CurseForge

Estas capturas documentan el flujo visual actual de DpsFoundry Core y Link.
Fueron aportadas por Daniel el 2026-09-28 desde perfiles guardados y una sesión
anterior de juego mientras la suscripción actual no está disponible. Sirven como
material temporal de la ficha beta; no se presentan como una captura en tiempo
real de una versión de WoW determinada.

- `01-core-simulation.png`: builds y resultados de simulación en Core.
- `02-link-weights.png`: panel de pesos de Link.
- `03-link-export-reload.png`: exportación local hacia Core y recarga.
- `04-core-character.png`: perfil y equipo guardado en Core.
- `05-link-item-score.png`: score de equipo en tooltip.

Antes de una publicación estable, reemplazarlas por capturas actuales cuando el
acceso al juego esté disponible de nuevo.
