# DpsLab — Distribution

Guides for the supported interface languages:

- [DISTRIBUTION-es.md](DISTRIBUTION-es.md) — Español
- [DISTRIBUTION-en.md](DISTRIBUTION-en.md) — English
- [DISTRIBUTION-pt-BR.md](DISTRIBUTION-pt-BR.md) — Português do Brasil

All guides describe the same reduced Windows package: the DpsLab desktop app,
the DpsLab WoW addon, and the SimulationCraft executable. The package includes
the SimulationCraft GPL v3 notice. Names, realms, builds, talent strings, paths,
numbers and raw SimulationCraft output are not translated.
