# DpsFoundry Link — CurseForge open-beta listing

## Project details

- Name: **DpsFoundry Link**
- Proposed category: **Utilities**
- Game: World of Warcraft Retail
- Type: addon
- State: open beta

## Short description

DpsFoundry Link observes your character locally, exports its profile to
DpsFoundry Core, and shows gear scores from compatible weights.

## Description

DpsFoundry Link accompanies DpsFoundry Core through **analyze → decide → sync
→ play → refine**. Export your character and loadouts from the game to Core,
import calculated weights, and view scores on compatible gear tooltips.

It is not a real-time connection and does not automate gameplay. Data moves
locally between the addon and desktop app. The beta supports the existing Core
workflow for supported classes and specializations.

## Quick start

1. Install Link at `World of Warcraft/_retail_/Interface/AddOns/DpsLab`.
2. In game, use `/dpslab export app` and confirm `/reload`.
3. Open DpsFoundry Core, import the export, and simulate the chosen builds.
4. Export selected weights from Core and import them in Link to see scores.
